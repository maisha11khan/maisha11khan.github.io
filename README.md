# Maisha Zaman Khan — Portfolio

A responsive single-page portfolio website built with plain HTML, CSS and JavaScript.

## Run locally
1. Open `index.html` in a browser, or use VS Code Live Server.
2. Replace the LinkedIn placeholder with your actual profile URL.
3. Add your CV PDF if you want a CV download button.
4. Add GitHub links for NeuralNest and Dune Blaster Rally if available.

## Deploy with GitHub Pages
1. Create a public repository, e.g. `maisha11khan.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/root`.
5. Save. GitHub will provide the live URL.
